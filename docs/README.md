# Geometric Lib

## Общее описание
Библиотека для работы с геометрическими фигурами. Позволяет рассчитывать площадь и периметр круга, квадрата, прямоугольника и треугольника.

## Описание функций

### Circle (`circle.py`)

#### `area(r)`
Возвращает площадь круга по заданному радиусу.

**Параметры:**

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `r` | `float` | Радиус круга |

**Возвращаемое значение:**
* `float`: Площадь круга ($S = \pi \cdot r^2$).

**Пример использования:**
```python
from circle import area

print(area(5))  # 78.53981633974483
```

#### `perimeter(r)`
Возвращает длину окружности по заданному радиусу.

**Параметры:**

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `r` | `float` | Радиус круга |

**Возвращаемое значение:**
* `float`: длина окружности ($l = 2 \cdot \pi \cdot r$).

**Пример использования:**
```python
from circle import perimeter

print(perimeter(5))  # 15.707963267948966
```



### Square (`square.py`)

#### `area(a)`
Возвращает площадь квадрата по стороне.

**Параметры:**

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `a` | `float` | Сторона квадрата |

**Возвращаемое значение:**
* `float`: Площадь квадрата ($S = a \cdot 4$).

**Пример использования:**
```python
from square import area

print(area(5))  # 25
```

#### `perimeter(a)`
Возвращает периметр квадрата по стороне.

**Параметры:**

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `a` | `float` | Сторона квадрата |

**Возвращаемое значение:**
* `float`: Периметр квадрата ($P = a \cdot a$).

**Пример использования:**
```python
from square import perimeter

print(perimeter(5.0))  # 25.0
```



### Rectangle (`rectangle.py`)
#### `area(a, b)`
Возвращает площадь прямоугольника по двум сторонам.

**Параметры:**

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `a` | `float` | Первая сторона прямоугольника |
| `b` | `float` | Вторая сторона прямоугольника |

**Возвращаемое значение:**
* `float`: Площадь прямоугольника ($S = a \cdot b$).

**Пример использования:**
```python
from rectangle import area

print(area(2, 4.5))  # 9.0
```

#### `perimeter(a, b)`
Возвращает периметр прямоугольника по стороне.

**Параметры:**

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `a` | `float` | Первая сторона прямоугольника |
| `b` | `float` | Вторая сторона прямоугольника |

**Возвращаемое значение:**
* `float`: периметр прямоугольника ($P = (a + b) \cdot 2$).

**Пример использования:**
```python
from rectangle import perimeter

print(perimeter(6, 4))  # 20
```




### Trigangle (`triangle.py`)
#### `area(a, h)`
Возвращает площадь треугольника по основанию и высоте.

**Параметры:**

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `a` | `float` | Основание треугольника |
| `h` | `float` | Высота треугольника |

**Возвращаемое значение:**
* `float`: Площадь треугольника ($S = (a \cdot h) / 2$).

**Пример использования:**
```python
from triangle import area

print(area(2, 4.5))  # 4.5
```

#### `perimeter(a, b, c)`
Возвращает периметр треугольника по трём сторонам.

**Параметры:**

| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `a` | `float` | Первая сторона треугольника |
| `b` | `float` | Вторая сторона треугольника |
| `c` | `float` | Третья сторона треугольника |

**Возвращаемое значение:**
* `float`: периметр треугольника ($P = (a + b + c)$).

**Пример использования:**
```python
from triangle import perimeter

print(perimeter(3, 4, 5))  # 12
```
