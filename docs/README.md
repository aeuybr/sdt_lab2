# Geometric Lib

## Общее описание
Библиотека для работы с геометрическими фигурами. Позволяет рассчитывать площадь и периметр круга, квадрата, прямоугольника и треугольника.

## Описание функций

### Circle (`circle.py`)
* `area(r)`
  * Принимает радиус `r`, возвращает площадь круга.
  * Формула: `S = π * r²`
  * Пример вызова: `area(5)` -> `78.53981633974483`
* `perimeter(r)`
  * Принимает радиус `r`, возвращает длину окружности.
  * Формула: `P = 2 * π * r`
  * Пример вызова: `perimeter(5)` -> `31.41592653589793`

### Square (`square.py`)
* `area(a)`
  * Принимает сторону `a`, возвращает площадь квадрата.
  * Формула: `S = a²`
  * Пример вызова: `area(4)` -> `16`
* `perimeter(a)`
  * Принимает сторону `a`, возвращает периметр квадрата.
  * Формула: `P = 4 * a`
  * Пример вызова: `perimeter(4)` -> `16`

### Rectangle (`rectangle.py`)
* `area(a, b)`
  * Принимает стороны `a` и `b`, возвращает площадь прямоугольника.
  * Формула: `S = a * b`
  * Пример вызова: `area(3, 5)` -> `15`
* `perimeter(a, b)`
  * Принимает стороны `a` и `b`, возвращает периметр прямоугольника.
  * Формула: `P = 2 * (a + b)`
  * Пример вызова: `perimeter(3, 5)` -> `16`

### Triangle (`triangle.py`)
* `area(a, h)`
  * Принимает основание `a` и высоту `h`, возвращает площадь треугольника.
  * Формула: `S = (a * h) / 2`
  * Пример вызова: `area(6, 4)` -> `12.0`
* `perimeter(a, b, c)`
  * Принимает стороны `a`, `b`, `c`, возвращает периметр треугольника.
  * Формула: `P = a + b + c`
  * Пример вызова: `perimeter(3, 4, 5)` -> `12`
